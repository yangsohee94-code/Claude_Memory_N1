# Quick Image Insert

구텐베르크 에디터 툴바에 📷 이미지 삽입 버튼을 추가하는 워드프레스 플러그인.

## 설치 방법

1. `quick-image-insert` 폴더를 통째로 워드프레스의 `/wp-content/plugins/` 폴더에 업로드
2. 워드프레스 관리자 → **플러그인** → `Quick Image Insert` **활성화**

## 사용 방법

1. 글 에디터에서 **단락, 제목, 목록, 인용구** 블록 클릭
2. 툴바에 나타나는 📷 (이미지) 버튼 클릭
3. 미디어 라이브러리에서 이미지 검색 후 선택
4. 현재 블록 바로 아래에 이미지 블록이 자동 삽입됨

## 버튼이 보이는 블록

- 단락 (Paragraph)
- 제목 (Heading) ← H2, H3 등
- 목록 (List)
- 인용구 (Quote / Pullquote)
- 커버 (Cover)
